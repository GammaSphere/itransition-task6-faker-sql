# Faker SQL

A web application that generates random, fake user contact information. All data generation is implemented as **PostgreSQL stored procedures** (schema `faker`), a small "Faker" library in SQL. The Python app (Flask) only calls the procedures and renders HTML.

## What it does

Choose a locale (**English (United States)** or **Deutsch (Deutschland)**) and a seed, and the app shows a batch of users. Press *Load batch N* for the next batch with the same arguments, or change the locale, seed or batch size. Every user has:

- a **full name** with variations: titles (Mr., Dr., Herr, Frau Prof. Dr.), middle names or initials, double surnames, suffixes (Jr., PhD), nobility particles (von), "Last, First" order;
- a **postal address** from real postcode / city / state data, in the locale's format: house number, street word and suffix (Ave / Avenue, Goethestraße / Goethestr.), apartment or floor, one or two lines, ZIP+4, P.O. box or Postfach;
- a **geolocation** uniformly distributed on the sphere (`latitude = asin(2u − 1)`, not a uniform latitude);
- **physical attributes**: height from a normal distribution (Box–Muller), weight from height and a log-normal BMI, eye colour, hair colour and blood type with population frequencies, in the locale's units (5'11", 176 lb / 1,82 m, 79,8 kg);
- a **phone number** from weighted masks (NANP rules for the US, area codes and mobile prefixes for Germany);
- an **e-mail address** built from the person's name, transliterated (Jürgen → juergen);
- a **bio** generated by an order-2 **Markov chain** trained on public-domain novels in the locale's language (the optional part of the task).

Reproducibility: every value is a pure function of (locale, seed, position), where position = batch × batch size + index. The same arguments give the same users on every server: the test suite produces byte-identical output on a local PostgreSQL 17 and on Neon's PostgreSQL 18.

## The SQL library in one minute

```sql
SELECT full_name, address, phone, email FROM faker.generate_users('en_US', 42);      -- batch 0, 10 users
SELECT * FROM faker.generate_users('de_DE', 42, 3, 10, false);                    -- batch 3, no bio
SELECT * FROM faker.benchmark('en_US', 100000);                                   -- users per second
SELECT faker.random_normal(12345, 1, 170, 7), * FROM faker.random_point_on_sphere(12345);
```

The functions are layered and small: random primitives (`random_uniform`, `random_normal`, `random_point_on_sphere`, `random_digits`, …) → weighted picks from lookup tables (`pick_name`, `pick_word`, `pick_format`, `pick_place`) → formatting (`fill_template`, `format_height`, …) → field generators (`person_name`, `address`, `phone_number`, `email_address`, `physical_attributes`, `markov_text`) → `generate_users`. Every function, argument and algorithm is described in **[docs/FAKER_SQL.md](docs/FAKER_SQL.md)**.

The database is designed for extensibility: one `names` table, one `places` table, one `words` table and one `formats` table for all locales, each with a `locale` column. A new locale is new rows, not new tables or code.

Lookup sizes: 3 000 US and 2 000 German given names, 6 001 US and 30 429 German surnames, 40 977 US and 15 050 German postcodes with their city and state, 3 200+ German street names, and a Markov chain of about 200 000 transitions per language.

## Benchmark

`faker.benchmark()` inside the database, one session, local PostgreSQL 17 (the full tables, including the deployed Neon database at about 7 200 users/s, are in [docs/BENCHMARK.md](docs/BENCHMARK.md)):

| | en_US | de_DE |
| --- | ---: | ---: |
| without bio text | 8 332 users/s | 9 428 users/s |
| with Markov bio text | 4 068 users/s | 4 155 users/s |

Users at different positions are independent, so parallel sessions scale it further (about 50 000 users/s with 8 sessions on a desktop CPU).

## Run it locally

```bash
docker compose up -d                                       # PostgreSQL 17 on 127.0.0.1:5544
python -m venv .venv && . .venv/bin/activate               # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export DATABASE_URL=postgresql://faker:faker@127.0.0.1:5544/faker
python db/setup.py                                         # schema, procedures, lookup data
flask --app app.main run                                   # http://127.0.0.1:5000
pip install pytest && pytest -q                            # 27 tests: reproducibility, formats, distributions
python scripts/benchmark.py                                # users/s table, see docs/BENCHMARK.md
```

`tools/build_data.py` rebuilds `db/data/*.csv.gz` from the raw sources (download links in its docstring), and `tools/build_map.py` builds the equal-area world map used by the app.

## Project layout

```text
db/sql/01_schema.sql       tables, indexes, CALL faker.refresh_weights()
db/sql/02_random.sql       counter-based random numbers, normal / log-normal, sphere, digit masks
db/sql/03_pick.sql         weighted picks by inverse transform sampling (cdf column + B-tree)
db/sql/04_format.sql       templates, transliteration, units, coordinates
db/sql/05_generators.sql   name, address, phone, e-mail, geolocation, body, Markov text
db/sql/06_api.sql          generate_users, generate_user, list_locales, benchmark, lookup_sizes
db/seed/<locale>.sql       curated vocabularies and formats per locale
db/data/*.csv.gz           names, places, street names, Markov chain (built by tools/build_data.py)
db/setup.py                creates everything in a database
app/                       Flask app: generator, distribution check, benchmark, docs pages
index.py, vercel.json      Vercel deployment (Flask as a Python serverless function)
tests/                     pytest suite against a live database
scripts/benchmark.py       benchmark (results in docs/BENCHMARK.md)
```

## Deployment

The app runs on Vercel as a Python serverless function (region `fra1`) and the database on Neon's free tier (`aws-eu-central-1`). The only setting is `DATABASE_URL`; use Neon's pooled connection string for the app and the direct one for `db/setup.py`.

## Data sources

US given names: SSA baby names (public domain). US surnames: US Census 2000 (public domain). German names: Faker (MIT) and NameDatabases (MIT). Postcodes, cities and regions: [GeoNames](https://www.geonames.org/) (CC BY 4.0). Markov corpora: Project Gutenberg (public domain). World map: Natural Earth (public domain).
